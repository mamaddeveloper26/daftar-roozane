# دفتر روزانه

اپلیکیشن دفتر روزانه فارسی با تاریخ شمسی و ساعت ایران.

## قابلیت‌ها
- افزودن نوشته با عنوان، متن و دسته‌بندی
- نمایش کارت‌محور
- فیلتر بر اساس دسته (کار، شخصی، ورزش، یادداشت)
- ثبت خودکار تاریخ شمسی و ساعت (منطقه زمانی تهران)
- ذخیره روی گوشی (localStorage)
- قابل نصب روی صفحهٔ اصلی به‌صورت PWA

## استفاده
1. این ریپو را با GitHub Pages منتشر کنید، یا فایل‌ها را روی هر هاست استاتیک بگذارید.
2. لینک را در مرورگر گوشی (Chrome) باز کنید.
3. منوی مرورگر → **Add to Home screen** / **نصب اپ**.

## فایل‌ها
- `index.html` — ساختار
- `styles.css` — ظاهر
- `app.js` — منطق
- `manifest.json` / `sw.js` — نصب آفلاین
