# دفترچه روزانه

دفترچه فارسی، راست‌چین و قابل نصب روی گوشی با پشتیبانی کامل از استفاده آفلاین پس از اولین بار باز شدن و ذخیره شدن فایل‌ها.

## امکانات
- ثبت یادداشت آزاد با عنوان اختیاری و دسته‌بندی
- تاریخ شمسی و ساعت خودکار (منطقه زمانی تهران)
- افزودن چند عکس به هر یادداشت و ذخیره محلی عکس‌ها
- جستجو، فیلتر و مرتب‌سازی
- ویرایش و حذف با تأیید
- ذخیره در IndexedDB مرورگر/گوشی
- خروجی و بازیابی فایل پشتیبان شامل عکس‌ها
- صفحه درباره با عبارت «ساخته شده توسط ممد»

## نصب و استفاده
1. GitHub Pages را برای شاخه main و پوشه root فعال کنید.
2. آدرس Pages را یک‌بار با Chrome باز کنید تا فایل‌های برنامه ذخیره شوند.
3. از منوی Chrome گزینه Install app یا Add to Home screen را انتخاب کنید.
4. بعد از نصب، برنامه بدون اینترنت باز می‌شود.

## نکته مهم درباره حفظ اطلاعات
اطلاعات در حافظه محلی همان گوشی ذخیره می‌شود. پاک کردن داده‌های مرورگر/برنامه یا خرابی گوشی می‌تواند داده محلی را از بین ببرد؛ بنابراین از صفحه «پشتیبان» مرتب فایل پشتیبان بگیرید و آن را خارج از گوشی نگه دارید. نصب نسخه جدید برنامه به‌خودی‌خود دیتابیس IndexedDB را پاک نمی‌کند.

هیچ سرویس، فونت، کتابخانه یا API اینترنتی در زمان اجرای برنامه استفاده نمی‌شود.
